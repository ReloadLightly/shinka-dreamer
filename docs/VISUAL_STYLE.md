# Chromatic Field v1 — ShinkaDreamer

Adopted from [ReloadLightly/actir-backprop-neat](https://github.com/ReloadLightly/actir-backprop-neat/blob/main/docs/VISUAL_STYLE.md)
and its `scripts/visual_theme.py`, read on 2026-10-08. The local shared helper is
`scripts/visual_theme.py`; it loads no experiment data. Existing v2 figures remain
unchanged.

Use opaque warm white `#FFFEFC`, text `#161625`, secondary `#6F6A78`, cobalt
`#3534CF`, magenta `#C93683`, orange `#F26A37` and thin rules `#DCD7E0`.
DejaVu Sans at readable 10–12 pt, 16 pt titles, nominal 10-inch width; provide
SVG, PDF and PNG. Preserve individual observations, uncertainty, missing values
and failures. Captions and linked CSV/JSON carry the evidence in searchable form.
Fields use peach-to-cobalt only for labelled numeric probabilities.

For this wave: evolved/online is cobalt; frozen is magenta; known-law is orange;
memory and historical controls use secondary/muted colors with distinct markers.
Lineage means actual source ancestry, not causal necessity. Inspect exports at
960 px width and dense diagrams at full size; keep readable gutters and labels.
