Archive seed inspirations refer to the copy on the listed island; exact IDs are preserved in the review and its [immutable lineage snapshot](../artifacts/campaign-v3/source-review-lineage-0-7.json). This snapshot materializes fields already captured during the initial review; its creation timestamp is not a new observation of native state. Four island copies of the seed count as **one candidate slot**, not four independent searches. No migration event was captured for this batch in that initial review. Later migrations and current island locations belong to the [expanding lineage archive](../artifacts/campaign-v3/lineage.json). Gen5's first patch failed to apply and the second repaired it: two patch attempts, one accepted candidate slot. [Attempt records](../artifacts/campaign-v3/attempts.json) preserve that failure.

Gen6 is a useful negative branch: the proposed survival-conditioned planner scored below both its parent and the seed on development. Its intended benefit is not an observed result. Gen5 also contains a source-level forecasting mismatch: it treats a closed door as blocked when forecasting the transition in which the agent opens it; this review did not quantify its effect.

`learn=False` has a coherent parameter-freezing interpretation in these directional learners, while mapping and occupancy-state inference continue. That does not guarantee identical inferred occupancy: a changed law can change the filter's state. In gen2 and gen7, `predictive_planning=False` substitutes the current uniform law but still consumes persistent fog previously propagated under learned dynamics. It therefore does **not** remove all adaptation influence on control. Gen1/3/4/6 instead recompute planning forecasts under uniform dynamics; gen5 substitutes the seed's fixed proximity-risk heuristic. These interventions differ in meaning and require source-specific runtime checks.

The [gen1 development audit](../artifacts/campaign-v3/mechanism-gen1-smoke/summary.json) preserves a negative result: online learning worsened prediction on identical experience despite better on-policy prediction loss, with no observed escape improvement in its small smoke comparison. The [gen4 review](../artifacts/campaign-v3/mechanism-gen4-review.json) is source evidence only. Better development task scores, better prediction, causal control benefit and reliable discovery remain separate claims.
