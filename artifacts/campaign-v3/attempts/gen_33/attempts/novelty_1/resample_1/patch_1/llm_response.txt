<DESCRIPTION>
Carry enemy intensity between observations instead of rebuilding hidden enemies from a uniform density each turn. Condition the previous forecast on visible empty cells, remove visible enemies from hidden mass, and normalize the remainder to the unresolved enemy count. A small diffuse component permits recovery from terrain changes and approximation errors.

Propagate this belief through the existing blocked-attempt kernels and use it in both forecasts and planning hazards. Maintain separate adaptive and uniform histories for the prediction-use intervention. This is an approximate anonymous intensity filter, with the existing overlap approximation retained. It aims to distinguish recently cleared passages from likely incoming threats; performance improvement remains to be evaluated.
</DESCRIPTION>
