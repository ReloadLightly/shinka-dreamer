<DESCRIPTION>
Add a bounded stall controller that measures progress using legal route length, avoiding false stalls on winding paths. Repeated position–target cycles trigger a short, low-risk observation detour, selected using route cost, distance to the original objective, and fresh observation opportunities. Detours expire after six decisions and have a cooldown. During recovery, waiting receives an additional penalty only when a low-hazard immediate move exists. Normal planning, learned dynamics, and visible-enemy exclusion remain intact. This targets avoidable waiting without globally reducing survival pressure; performance improvement remains to be evaluated.

def _route_steps(m, target):
    # Reverse breadth-first search measures progress independently of
    # changing enemy forecasts and accumulated visitation penalties.
    steps = {target: 0}
    queue = [target]
    for p in queue:
        for dx, dy in STEPS:
            q = _add(p, (dx, dy))
            if q in steps:
                continue
            if _wall(m["map"], q, m["keys"] >= 2 or m["door_open"], True):
                continue
            if _legal(m, q, (-dx, -dy)):
                steps[q] = steps[p] + 1
                queue.append(q)
    return steps
