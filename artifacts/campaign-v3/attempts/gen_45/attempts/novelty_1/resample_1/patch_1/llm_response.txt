<DESCRIPTION>
Maintain a responsive movement estimate alongside the existing slower learner, with a uniform component for uncertainty about unseen dynamics changes. Propagate each law independently through the existing two forecast steps, then average occupancy probabilities. This preserves uncertainty about a persistent movement law without increasing planning depth.

Compute second-step collision probabilities from each enemy’s joint pre-move and post-move occupancy, subtracting overlapping stay events. The current independence approximation can overprice waiting for blocked enemies to clear a route. Preserve mapping, exploration, and both learning and prediction-use interventions. These are proposed improvements; their control benefit requires evaluation.
</DESCRIPTION>

def _forecasts(m, law, adaptive=True):
    opened = m["door_open"] or (
        m["keys"] >= 2 and any(
            m["map"].get(_add(m["pos"], d)) == 3
            for d in ((1, 0), (-1, 0), (0, 1), (0, -1))))
    sources = sorted(m["enemies"])
    background = max(0, 3 - len(sources)) / 140.0
    forecasts = [{}, {}]
    collisions = [{}, {}]
    def hidden_base(p, horizon):
        if _distance(p, m["pos"]) <= 2 - horizon:
            return 0.0
        if p in m["local"]:
            return background * min(1.0, .18 * horizon)
        return background
    # Keep each movement law fixed throughout its forecast. All enemies
    # share that law; average only after computing joint occupancy.
    for weight, expert_law in _forecast_laws(m, law, adaptive):
        tracks = [{e: 1.0} for e in sources]
        kernels = {}
        def kernel(p):
            if p not in kernels:
                grouped = {}
                for d, probability in zip(MOVES, expert_law):
                    q = _destination(m["map"], p, d, opened)
                    grouped[q] = grouped.get(q, 0.0) + probability
                kernels[p] = grouped
            return kernels[p]
        for index, horizon in enumerate((1, 2)):
            following = []
            cells = set(m["map"])
            for track in tracks:
                new = {}
                for p, mass in track.items():
                    for q, probability in kernel(p).items():
                        new[q] = new.get(q, 0.0) + mass * probability
                following.append(new)
                cells.update(track)
                cells.update(new)
            for p in cells:
                occupancy = collision = 0.0
                if not _wall(m["map"], p, opened):
                    base = hidden_base(p, horizon)
                    empty = 1.0 - base
                    # Preserve the background approximation, while treating
                    # visible enemy self-transitions explicitly.
                    old_base = (
                        hidden_base(p, horizon - 1) if horizon > 1 else 0.0
                    )
                    safe = (1.0 - old_base) * (1.0 - base)
                    stay = kernel(p).get(p, 0.0)
                    for before, after in zip(tracks, following):
                        previous_mass = before.get(p, 0.0)
                        next_mass = after.get(p, 0.0)
                        union = previous_mass + next_mass - previous_mass * stay
                        empty *= 1.0 - min(1.0, max(0.0, next_mass))
                        safe *= 1.0 - min(1.0, max(0.0, union))
                    occupancy = min(1.0, max(0.0, 1.0 - empty))
                    collision = min(1.0, max(0.0, 1.0 - safe))
                forecasts[index][p] = (
                    forecasts[index].get(p, 0.0) + weight * occupancy
                )
                collisions[index][p] = (
                    collisions[index].get(p, 0.0) + weight * collision
                )
            tracks = following
    return forecasts, background, opened, collisions
