<DESCRIPTION>
Carry door state through each planning branch. Interaction opens the door before movement only when the simulated agent has both keys and is cardinally adjacent; subsequent enemy transitions and diagonal legality use that resulting state. Cache separate enemy kernels for open and closed doors, and account for keys collected along simulated paths. Retain the existing always-interact policy.

Store the observed preceding door state separately from the forecast state. Learn opening transitions using the confirmed resulting door state, avoiding attribution of newly legal enemy movements to a change in movement law. This targets transition-model errors without changing the objective or predictive interventions. Performance improvement remains untested.
</DESCRIPTION>
