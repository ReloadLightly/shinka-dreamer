<DESCRIPTION>
Learn uniform, slow-adapting, and fast-adapting movement experts, weighting them by the likelihood of subsequently observed anonymous transitions. This lets stationary evidence accumulate while retaining a responsive alternative after a dynamics change. Blocked attempts remain probability mass on staying.

Propagate each expert separately through the existing three-step planner. Penalize expected collision hazard plus bounded disagreement among plausible experts, and invoke this planner proactively near the proposed route rather than only after stalling. Preserve the existing low-risk first-move restriction and keep repetition penalties specific to recovery. Export expert weights alongside the learned movement law. These changes aim to reduce deaths without extending the planning horizon; performance remains to be evaluated.
</DESCRIPTION>

def _expert_probabilities(m):
    return m.get("expert_mass", [.30, .50, .20])


def _expert_laws(m):
    laws = [[1. / 9.] * 9]
    for counts, prior in ((m["motion"], 1.),
                          (m.get("fast_motion", [0.] * 9), .5)):
        total = sum(counts) + 9. * prior
        laws.append([.90 * (v + prior) / total + .10 / 9.
                     for v in counts])
    return laws


def _motion_weights(m):
    laws = _expert_laws(m)
    masses = _expert_probabilities(m)
    return [sum(mass * law[i] for mass, law in zip(masses, laws))
