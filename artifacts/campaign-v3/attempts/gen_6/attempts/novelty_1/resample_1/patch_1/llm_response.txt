survival_conditioned_beam
</NAME>
<DESCRIPTION>
Replace the planner’s sum of marginal collision penalties with survival-conditioned enemy trajectories. After each hypothetical agent move, remove enemy paths that would already have caused a collision and condition subsequent predictions on survival. This avoids repeatedly charging for the same dangerous trajectories across the planning horizon, while preserving both pre-movement and post-movement collision checks.
A bounded beam retains alternatives for each first action, including waiting. Hidden-enemy risk remains conservative, and learned movement laws, anonymous dynamics updates, and prediction interventions remain intact. This targets the current agent’s long escape times and timeouts without lowering its immediate collision penalty. Performance gains require evaluation.
</DESCRIPTION>

    # Along a hypothetical path, it is conditioned on surviving every
    # previous agent move. No cross-observation identity matching is used.
    beliefs = tuple({p: 1.0} for p in sorted(m["enemies"]))
    # Entries: estimated total cost, incurred cost, cell, first move, beliefs.
    beam = [(terminal.get(start, 10000.0), 0.0,
             start, (0, 0), beliefs)]
    completed = []
    for t in range(depth):
        candidates = []
        for _, cost, p, first, source_beliefs in beam:
            # Cache unconditioned propagation once per parent path.
            propagated = []
            for distribution in source_beliefs:
                following = {}
                for source, mass in distribution.items():
                    for destination, probability in kernels.get(source, ()):
                        following[destination] = (
                            following.get(destination, 0.0)
                            + mass * probability
                        )
                propagated.append(following)
            for direction in MOVES:
                if not _legal(m, p, direction):
                    continue
                q = _add(p, direction)
                if t == 0 and q in m["enemies"]:
                    continue
                hidden_hazard = hidden_collisions[t].get(q, 0.02)
                if hidden_hazard >= 1.0 - 1e-10:
                    continue
                collision_cost = -math.log(
                    max(1e-12, 1.0 - hidden_hazard)
                )
                conditioned = []
                feasible = True
                for distribution, following in zip(
                    source_beliefs, propagated
                ):
                    # Stepping onto an enemy kills before it can move.
                    # Remove all transitions from q, then remove arrivals
                    # at q after enemy movement.
                    pre_collision = distribution.get(q, 0.0)
                    surviving = dict(following)
                    if pre_collision:
                        for destination, probability in kernels.get(q, ()):
                            surviving[destination] = max(
                                0.0,
                                surviving.get(destination, 0.0)
                                - pre_collision * probability
                            )
                    surviving.pop(q, None)
                    survival = min(1.0, sum(surviving.values()))
                    if survival <= 1e-12:
                        feasible = False
                        break
                    collision_cost -= math.log(survival)
                    conditioned.append({
                        cell: mass / survival
                        for cell, mass in surviving.items()
                        if mass > 0.0
